# Netflix Analytics Dashboard – Power BI

## Project Overview

This project is a **one-page Netflix Analytics Dashboard** built in **Power BI** to analyze Netflix’s content catalog and provide business-oriented insights. The dashboard focuses on content composition, release trends, geographic distribution, audience ratings, and genre popularity to support data-driven decision-making.

## Objectives

* Analyze the overall Netflix content library.
* Compare **Movies vs TV Shows**.
* Identify the **top content-producing countries**.
* Understand **content growth over time**.
* Explore **rating distribution** and **genre concentration**.
* Build an interactive executive-style dashboard for quick insights.

---

## Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **Microsoft Excel** (data preparation)

---

## Key Features

* KPI cards for Total Content, Movies, and TV Shows.
* Interactive slicers for Content Type, Release Season, Runtime, and Release Year Range.
* Trend analysis of titles released over time.
* Top content-producing countries analysis.
* Content rating distribution.
* Top 5 genres by content count.
* Movie vs TV Show catalog split visualization.

---

## Key Insights

* **Movies account for nearly 70%** of the Netflix catalog.
* Content releases increased significantly after **2010**.
* The **United States and India** are the largest content contributors.
* **TV-MA and TV-14** are the most common audience ratings.
* **Drama and International Movies** dominate the genre distribution.

---

## Data Preparation

* Handled missing values in categorical columns.
* Split multi-value fields such as **Country** and **Genre** for accurate analysis.
* Created runtime and season-based segmentation.
* Standardized data types for dates and numeric fields.

---

## Business Value

The dashboard provides an executive view of Netflix’s content portfolio, helping stakeholders understand catalog composition, growth patterns, regional content contribution, and audience targeting for strategic content planning.
